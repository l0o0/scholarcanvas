# Markdown / Canvas 上线前补充功能

## 使用入口

- **整组复制与跨白板粘贴**：选中多个卡片或分组后按 `Ctrl/Cmd+C`，在另一块白板按 `Ctrl/Cmd+V`。保留组内节点、样式和内部连线，生成新 ID；不复制指向未选节点的连线。粘贴支持一步撤销/重做。正在输入文字时保留普通文本剪贴板行为。“更多 → 复制选区副本”在当前白板生成副本。
- **选区整理**：选中节点后使用“更多 → 自动布局”，只整理选区；分组与成员一起移动。不选节点时会先确认是否整理全白板。
- **卡片 Markdown 阅读**：笔记卡片展示标题、强调、列表、代码、链接、公式和脚注。双击或使用“编辑正文”修改原始 Markdown，`Ctrl/Cmd+Enter` 提交、`Esc` 取消。内容超出卡片高度时可在卡片内滚动。
- **公式和脚注**：Markdown 阅读模式、HTML 导出及笔记卡片支持 `$…$`、`$$…$$`、围栏 `math` 代码块和 `[^name]` 脚注。公式使用随插件打包的 KaTeX 和原生 MathML，无需联网下载字体；脚注支持跳转和返回。编辑模式保留公式、脚注源码。
- **文库全文搜索**：Markdown 编辑器“更多 → 搜索文库笔记”，搜索当前文库可读取的 Markdown 附件标题、文件名和正文，多个词按 AND 匹配，显示前 100 条结果；点击结果打开笔记并定位正文命中处。搜索基于已保存/已索引内容，读取失败或尚未下载的笔记不纳入结果。
- **Canvas 搜索**：`Ctrl/Cmd+F` 或“更多 → 搜索白板”，搜索卡片正文与标题；`Enter` 定位下一条，`Shift+Enter` 定位上一条，`Esc` 关闭。
- **工作状态恢复**：记录打开的 Markdown/Canvas 标签页或独立窗口。Markdown 记住编辑/阅读模式、光标和滚动位置；Canvas 视口沿用文档保存值。重新启动插件时重开上次仍打开的文档，主动关闭的文档不会自动重开。状态保存在当前 Zotero 配置的本地偏好中，最多记录 100 个文档。
- **PDF 批注转 Markdown**：右键文献条目或 PDF 附件 →“从 PDF 批注生成 Markdown”，勾选批注后生成笔记。包含摘录、评论、页码以及定位到原 PDF 批注的 Zotero 链接；支持个人库和群组库。只读文库不能创建笔记。

## 当前边界

- 批注导出处理文字摘录和评论，不复制纯图片/区域截图；没有文字或评论的批注不列出。
- 跨白板复制保留 Zotero 文献引用，不拷贝文献 PDF 原件，也不搬运 Markdown 文本中引用的相对路径图片。目标环境仍需能访问这些资源。
- Markdown 源文件与 Obsidian 导出保留标准公式和脚注语法。Canvas 的 SVG 导出仍采用现有文本导出方式，不等同于网页中的 Markdown 排版。
- 自动恢复只恢复已保存内容；未保存内容仍由保存、冲突保护和本地历史机制处理。

## 验证

核心逻辑与 DOM 流程覆盖分组/连线复制、选区布局、跨白板粘贴及撤销、公式/脚注安全渲染与跳转、全文匹配定位、批注选择及只读限制、工作状态和编辑器通道隔离。fake-Zotero 集成测试及浏览器开发页用于回归检查。

真实 Zotero 的原生退出/重启时序及 PDF 阅读器跳转，需要安装构建后的 XPI 做最终验收；浏览器环境无法等价覆盖这些原生行为。
