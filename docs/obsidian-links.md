# Markdown 双链与目录导出

笔记集合以当前 Zotero library 为边界，包含该库的 Markdown 附件。个人库与不同群组库分别处理。

基础语法对应 [Obsidian 的内部链接格式](https://obsidian.md/help/links)：Wiki 使用文件名、标题和可选别名，标准 Markdown 对目标 URL 编码。

## 链接格式

输入 `[[` 搜索笔记；输入 `[[笔记名#` 选择标题。新链接直接保存为文件 Wikilink：

```md
[[阅读笔记--ABCD1234|阅读笔记]]
[[阅读笔记--ABCD1234#方法|方法部分]]
[[#当前标题|回到这里]]
```

`ABCD1234` 是 **Markdown 附件自身的 item key**。生成的目标文件名始终带 key，避免以后新增同名笔记导致歧义；别名独立控制显示文字。Zotero 内部仍用 `libraryID + attachment key` 确认身份，但新笔记链接的正文不再依赖 Zotero URI。文献和白板链接仍使用原有 Zotero URI。

也支持普通相对 Markdown 链接、手写 `[[笔记名]]`、标题别名与旧 Zotero 链接。同名手写链接会要求选择目标。带 key 的链接在附件改名后仍能在插件中找到原笔记；再次导出时统一生成当前文件名。

## 反向引用

标签页与独立窗口采用左侧目录、正文、右侧“引用此笔记”的布局。工具栏右侧的侧栏按钮独立控制引用面板；窄窗口默认收起，手动展开时浮在正文右侧。Zotero 原生侧边编辑器内保留嵌入式引用面板。

面板显示来源笔记、引用片段，点击返回引用位置。索引来自已保存正文，忽略 frontmatter、代码与图片；保存成功后更新，刷新按钮重新读取当前库。尚未保存的跨笔记改动不会提前进入反链索引。

## 导出

从 Markdown 标签页或独立窗口的“更多”菜单选择：

- **导出当前库笔记到 Obsidian…**：生成文件 Wikilink。
- **导出当前库笔记为 Markdown…**：生成 `[显示文字](文件名.md#标题)`。

导出前收集打开的编辑器快照并保存改动；同一附件在多个编辑器中存在未保存更改时停止，避免选错版本。选择父目录后创建新的 `zotero-markdown-export` 子目录，已有同名目录则递增编号。

笔记输出为 `文件名--KEY.md`，去除插件的 `zmd-` 前缀并清理不兼容文件名字符。原始 frontmatter 和未改写文本保持原样；引用的本地 `assets/` 图片复制到 `assets/KEY/`，隔离不同笔记中的同名图片。支持 Markdown/HTML 图片与 PNG、JPEG、GIF、WebP 的 Wiki 图片引用。裸 Wiki 图片名按本插件约定从该笔记的 `assets/` 中查找；同级、子目录和上级相对路径图片也会复制，引用式图片改写其定义；不同来源的同名图片使用独立目标路径。绝对路径及非图片资源保留并报告。详见 [保存保护与资源导出](file-safety.md)。

能对应导出笔记的旧 Zotero URI 转为文件链接。无法解析的链接、缺失图片和读取失败会列入导出目录的 `REPORT.md`，原链接保留或复制失败的目标明确报告。远程图片保留原 URL。

当前不包含块引用、笔记嵌入、关系图、跨文件自动改名重写或外部磁盘实时同步。Zotero 原附件仍分散在各自存储目录，导出的共享目录才用于在 Obsidian 等工具中整体打开。

## 验证

`pnpm test:unit` 覆盖解析、补全、库隔离、索引刷新竞态、导出改写和文件适配错误；`pnpm test:fake-zotero` 执行真实编辑器通信与反链 DOM 集成。`pnpm whiteboard:dev` 后打开 `/markdown.html` 可操作三篇附件与导出预览。目录写入测试替换 Zotero 文件 API；真实 Zotero 原生窗口和 Obsidian 应用仍需宿主验收。
